## Featured Project: GPCA Smart Weather Station

An IoT weather-monitoring system built for **Government Polytechnic College Anantnag**, co-developed with **Muhammad Yaseen**.

<div align="center">

[![Live Dashboard](https://img.shields.io/badge/▶_Open_Live_Dashboard-147D64?style=for-the-badge)](https://gpca-weather-station.onrender.com/)
[![Source Code](https://img.shields.io/badge/Source_Code-181717?style=for-the-badge&logo=github)](https://github.com/yawar2756/iot-weather-station)

</div>

**Data flow**

```mermaid
flowchart LR
    A[Environmental sensors] --> B[ESP8266 / ESP32]
    B -->|Wi-Fi telemetry| C[Flask backend / API]
    C --> D[(Supabase storage)]
    D --> E[Web dashboard]
```

**What it does**

- Collects readings from sensors on ESP8266/ESP32 boards
- Sends them over Wi-Fi to a Flask backend API
- Stores data in Supabase for persistence and history
- Displays readings and trends on a web dashboard, deployed on Render for remote access
