### 🚀 Featured Project: GPCA Smart Weather Station
> An end-to-end IoT monitoring ecosystem built to capture, ingest, and visualize environmental telemetry in real-time.

* **Architecture Flow:** ESP8266 / ESP32 Microcontrollers ➔ Python (Flask) REST API ➔ Supabase (PostgreSQL) Database ➔ Live Web Dashboard (Hosted on Render).
* **Key Features:**
  - Automated sensor telemetry collection (temperature, humidity, barometric pressure).
  - Secure REST endpoint ingestion with authentication & input validation.
  - Low-latency relational storage and historical time-series querying.
  - Responsive web dashboard providing live gauge metrics and historical trend charts.
